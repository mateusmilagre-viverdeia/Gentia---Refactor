# GENTIA — Extensão Chrome de Captura de Talentos

Captura perfis do LinkedIn diretamente para o seu banco de talentos no GENTIA com 1 clique.

## Como instalar (modo desenvolvedor)

1. Baixe e descompacte o arquivo `gentia-extension.zip`.
2. Abra `chrome://extensions` no Chrome (ou Edge/Brave/Arc).
3. Ative o **Modo do desenvolvedor** no canto superior direito.
4. Clique **Carregar sem compactação** e selecione a pasta da extensão.
5. O ícone do GENTIA aparece na barra do Chrome.

## Como usar

1. Navegue até qualquer perfil em `linkedin.com/in/...`
2. Clique no ícone do GENTIA na barra.
3. Faça login com seu e-mail/senha do GENTIA (apenas na primeira vez — sessão dura 7 dias).
4. (Opcional) Selecione uma vaga para vincular o perfil.
5. Clique em **Adicionar ao GENTIA**.

O candidato é processado, deduplicado e estruturado automaticamente.

## Privacidade

A extensão lê apenas o conteúdo visível da página do LinkedIn — não usa APIs privadas e não coleta dados de outras pessoas além do perfil que você está visualizando.
